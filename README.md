1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya!
JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis. Jika HTML membentuk struktur dan CSS mengatur tampilan, JavaScript bertugas mengatur perilaku halaman web seperti merespons klik dari pengguna, memunculkan notifikasi/pemberitahuan, mengolah data formulir, hingga mengubah isi atau gaya tampilan halaman secara langsung tanpa perlu memuat ulang (refresh) seluruh halaman

2. Jelaskan secara singkat apa itu jQuery dan kegunaannya!
jQuery adalah pustaka (library) JavaScript yang dirancang untuk mempermudah dan mempercepat penulisan kode JavaScript. Kegunaan utamanya adalah memersimpel manipulasi elemen HTML (DOM), penanganan event (seperti klik atau hover), pembuat animasi, serta pengiriman data ke server secara latar belakang (AJAX) dengan sintaks yang jauh lebih ringkas dan mendukung lintas peramban (cross-browser)

3. Jelaskan perbedaan JavaScript dan jQuery!
  Jenis/Bentuk: JavaScript adalah bahasa pemrograman tingkat tinggi yang berdiri sendiri, sedangkan jQuery adalah pustaka (library) yang dibuat menggunakan kode JavaScript
  Sintaks dan Kompleksitas Kode: JavaScript murni membutuhkan baris kode yang lebih panjang dan detail untuk melakukan manipulasi elemen. Sebaliknya, jQuery menyediakan penulisan kode yang lebih ringkas dan pendek untuk menyelesaikan instruksi yang sama
  Penggunaan/Pemasangan: JavaScript dapat langsung dijalankan oleh peramban (browser) tanpa perlu mengunduh file tambahan. Sementara itu, jQuery memerlukan tautan CDN (Content Delivery Network) atau berkas skrip jQuery tambahan agar fungsi fungsinya dapat dikenali
